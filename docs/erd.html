🗄️ Entity Relationship Diagram (ERD)

SIMKUR — Sistem Informasi Manajemen Kurikulum

Legend: PK = Primary Key FK = Foreign Key ⊃ = 1-to-many ⋈ = many-to-many

1. Master Kurikulum

CPL

  • id (PK, serial)
  • kode (unique)
  • deskripsi (text)
  • aspek (varchar)
  • created_at

CPMK

  • id (PK)
  • kode (unique)
  • deskripsi
  • cpl_id (FK → cpl)

SubCPMK

  • id (PK)
  • kode
  • deskripsi
  • cpmk_id (FK → cpmk)

MK

  • id (PK)
  • kode (unique)
  • nama
  • sks (int)
  • semester (int)

cpmk_mk (junction)

  • cpmk_id (FK → cpmk)
  • mk_id (FK → mk)
CPL (1) ⊃ CPMK (N)
CPMK (N) ⋈ MK (N) via cpmk_mk
CPMK (1) ⊃ SubCPMK (N)

2. Master Akademik

Mahasiswa

  • id (PK)
  • nim (unique)
  • nama
  • angkatan (int)
  • prodi
  • status

Dosen

  • id (PK)
  • nidn (unique)
  • nama
  • email
  • jabatan

TahunAkademik

  • id (PK)
  • kode (unique)
  • tahun_mulai (int)
  • semester
  • aktif (bool)

Kelas

  • id (PK)
  • mk_id (FK → mk)
  • tahun_akademik_id (FK)
  • dosen_id (FK → dosen)
  • kode_kelas
  • kapasitas
  • jadwal, ruang
Mahasiswa (1) ⊃ KRS (N)
Dosen (1) ⊃ Kelas (N)
TahunAkademik (1) ⊃ Kelas (N)
MK (1) ⊃ Kelas (N)

3. Transaksi KRS

KRS

  • id (PK)
  • mahasiswa_id (FK)
  • tahun_akademik_id (FK)
  • status (draft/diajukan/disetujui/ditolak)
  • total_sks
  • approved_by (FK → dosen)

KRSDetail

  • id (PK)
  • krs_id (FK → krs)
  • kelas_id (FK → kelas)
  • status
KRS (1) ⊃ KRSDetail (N)
Kelas (1) ⊃ KRSDetail (N)

4. Penilaian

KomponenPenilaian

  • id (PK)
  • kode (unique)
  • nama
  • kategori
  • aktif

BobotKomponenMK

  • id (PK)
  • kelas_id (FK)
  • komponen_id (FK)
  • bobot (0-100)

BobotCPMKMK

  • id (PK)
  • kelas_id (FK)
  • cpmk_id (FK)
  • bobot (0-100)

KonfigurasiPenilaianCPMK

  • id (PK)
  • kelas_id, cpmk_id, komponen_id
  • tahap, teknik, instrumen, kriteria
  • bobot

NilaiKomponen

  • id (PK)
  • krs_detail_id (FK)
  • komponen_id (FK)
  • nilai (0-100)
  • updated_by (FK → dosen)

NilaiCPMK

  • id (PK)
  • krs_detail_id (FK)
  • cpmk_id (FK)
  • nilai

NilaiMK

  • id (PK)
  • krs_detail_id (FK, unique)
  • nilai_angka
  • nilai_huruf
  • bobot_nilai
  • lulus

KetercapaianCPL

  • id (PK)
  • mahasiswa_id (FK)
  • cpl_id (FK)
  • tahun_akademik_id (FK)
  • skor_maks, total_skor
  • nilai_rata_rata, status

5. Auth

Users

  • id (PK)
  • username (unique)
  • password_hash
  • role (admin/dosen/mahasiswa)
  • ref_id (int, ke dosen/mahasiswa)
  • aktif
