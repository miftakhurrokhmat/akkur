2. Use Case Diagram

2.1 Aktor

  • Admin Prodi — pengelola sistem
  • Dosen — pengampu kelas & penilai
  • Dosen PA — penasihat akademik (approve KRS)
  • Mahasiswa — pengisi KRS & penerima nilai
  • Auditor — read-only untuk akreditasi

2.2 Use Case Textual

Admin Prodi
  ├─ Kelola CPL, CPMK, Sub-CPMK, MK
  ├─ Pemetaan CPMK↔MK
  ├─ Kelola Mahasiswa, Dosen, Tahun Akademik, Kelas
  ├─ Lihat Laporan CPL (Tabel 20)
  └─ Export Excel/PDF

Dosen (pengampu)
  ├─ Konfigurasi bobot komponen MK
  ├─ Konfigurasi bobot CPMK dalam MK
  ├─ Konfigurasi teknik per CPMK
  ├─ Input nilai komponen mahasiswa
  ├─ Hitung nilai CPMK, MK (otomatis)
  └─ Export Tabel 19 (Rumusan MK)

Dosen PA
  ├─ Lihat daftar KRS mahasiswa bimbingan
  ├─ Setujui KRS
  └─ Tolak KRS

Mahasiswa
  ├─ Login
  ├─ Buat KRS, tambah kelas, ajukan
  ├─ Lihat nilai MK
  ├─ Lihat ketercapaian CPL
  └─ Lihat transkrip

Auditor
  ├─ Lihat laporan CPL prodi
  ├─ Lihat laporan distribusi CPMK
  └─ Export laporan akreditasi
