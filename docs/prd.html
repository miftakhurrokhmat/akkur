1. Latar Belakang

Program studi wajib mengelola kurikulum berbasis CPL (Capaian Pembelajaran Lulusan) sesuai SN-DIKTI dan Seoul Accord. Saat ini pengelolaan CPL-CPMK-MK dan penilaian masih manual di Excel (20 file terpisah), menyebabkan:

  • Sulit melacak ketercapaian CPL mahasiswa
  • Tidak ada jejak audit perubahan kurikulum
  • Pelaporan akreditasi memakan waktu berminggu-minggu
  • Relasi CPMK↔MK tidak konsisten antar file

2. Tujuan Produk

  1. Sentra data kurikulum — semua entitas CPL/CPMK/Sub-CPMK/MK dalam satu database
  2. Keterlacakan penuh — CPL → CPMK → MK → Sub-CPMK → Nilai → Ketercapaian
  3. Otomasi perhitungan — nilai Sub-CPMK → CPMK → MK → CPL tanpa Excel
  4. Kepatuhan akreditasi — laporan otomatis sesuai Tabel 19 & 20
  5. Responsif — bisa diakses dari HP dosen

4. Persona Pengguna

👨‍💼 Admin Prodi

  • Tujuan: kelola master kurikulum, akun, tahun akademik
  • Pain point: revisi kurikulum manual di Excel sering bentrok
  • Kebutuhan: form CRUD, audit log, ekspor PDF

  • Tujuan: input nilai per komponen, lihat ketercapaian CPMK
  • Pain point: hitung rata-rata manual di Excel, sering salah
  • Kebutuhan: form input cepat, hasil kalkulasi otomatis

👨‍🎓 Mahasiswa

  • Tujuan: isi KRS, lihat nilai & ketercapaian CPL
  • Pain point: tidak tahu CPL mana yang sudah tercapai
  • Kebutuhan: dashboard CPL, transkrip digital

6. Alur Bisnis Utama

Alur 1 — Persiapan Semester

Admin Prodi
  ↓ Buat tahun akademik (2025/2026-Ganjil)
  ↓ Buat kelas TI012-A (dosen: Bu Dewi)
Dosen (Bu Dewi)
  ↓ Set bobot komponen: Partisipasi 10, Tugas 20, UTS 30, UAS 40
  ↓ Set bobot CPMK: CPMK051 40, CPMK052 30, CPMK053 30
  ↓ ✅ Kelas siap menerima mahasiswa

Alur 2 — Penilaian (Akhir Semester)

Bu Dewi
  ↓ Buka kelas TI012-A
  ↓ Input nilai Budi: Partisipasi=85, Tugas=80, UTS=75, UAS=90
  ↓ Klik "Simpan & Hitung"
  ↓ Sistem otomatis:
      - Nilai CPMK051 = 85×25% + 75×75% = 77.50
      - Nilai CPMK052 = 80×50% + 90×50% = 85.00
      - Nilai CPMK053 = 75×50% + 90×50% = 82.50
      - Nilai MK = 77.5×40% + 85×30% + 82.5×30% = 81.25 → A-
